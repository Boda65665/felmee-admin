# Адаптивность Felmee Admin

Цель: сделать рабочие экраны удобными на телефонах 360–430 px и планшетах
768–1024 px, сохранив серверные запросы, фильтры и бесконечную прокрутку.

Подход: существующие компоненты и токены. Ниже 768 px таблицы показываются
карточками с подписями полей, отдельными фильтрами и действиями. Выше —
таблицы с горизонтальной прокруткой внутри блока при необходимости.
Постоянное боковое меню включается с 1280 px; меньшие экраны используют drawer.
Диалоги ограничены экраном, формы переходят в одну колонку, кнопки доступны
для касаний, календарь и графики помещаются в экран.

- [x] Адаптировать оболочку, таблицу, карточки, вкладки, поиск, календарь и графики.
- [x] Адаптировать страницы и подписи мобильных таблиц.
- [x] Адаптировать формы, диалоги и переписку.
- [x] Проверить ширины 360, 390, 768, 1024, 1440 px, открытие меню/фильтров/
  модалок и подгрузку списка. Выполнить тесты, сборку и линтер.

Проверено: 16 маршрутов на ширинах 360, 390, 768, 1024, 1440 px; меню и Escape,
мобильный фильтр, календарь и форма уведомления на телефоне/планшете/desktop,
границы формы пользователя. Все 14 тестов проходят, build и lint завершаются успешно
(существующие предупреждения линтера и размера сборки сохраняются).
API на localhost:8080 во время проверки недоступен: браузерная проверка наполнения
выполнена с изолированными GET-ответами по контракту только в тестовом браузере.
Сервер не перезапускался; исходники приложения не получили тестовых данных.
Подгрузка списков проверена существующими тестами, live-проверка API не выполнялась.

Ограничения: бэкенд и сервер не перезапускать; API и данные не менять.
Внешние публикации и новые зависимости не нужны. Описания адаптивных
компонентов дополняют существующую `docs/design-system.md`.
