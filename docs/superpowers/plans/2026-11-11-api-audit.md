# Проверка интеграции Felmee Admin

Цель: удалить демонстрационные данные вне обзора бизнеса и его финансовых
деталей; исправить подтверждённые ошибки по контракту
`D:/projects/felmee-master/openapi.yaml` без изменения бэкенда.

- [x] Сравнить контракт с текущим клиентом, обновить локальную спецификацию и типы.
- [x] Убрать фиксированные личности, роли, фото и ветки ложного сохранения;
  использовать API, а при отсутствии данных — явное пустое состояние.
- [x] Исправить подтверждённые расхождения запросов, ответов и пагинации.
- [x] Проверить изменения тестами на контракт и регрессии, сборкой, линтером
  и безопасными HTTP-запросами к localhost:8080. Проверить работу админки.
- [x] Обновить проектную документацию и сообщить о недостающем API.

Ограничения: сервер не перезапускать, внешние проекты не редактировать,
существующие данные не изменять ради тестов. Моки допустимы только на
дашборде, GMV, выручке, среднем чеке и старом экране конверсии.
