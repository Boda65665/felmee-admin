# Единые попапы ошибок админки

Цель: ошибки действий и загрузки показываются в одном диалоге с понятным пояснением и исходным кодом API. Валидация остаётся у полей.

1. Вынести перевод ошибок в отдельный модуль. Добавить нормализацию Error/строки/кода банка и тесты сохранения кода.
2. Добавить очередь ошибок и общий диалог, исключающий дубли. Подключить ошибки TanStack Query после завершения повторов и заменить error-уведомления.
3. Перенести ошибки форм в общий диалог, сохраняя объект API-ошибки. Убрать красные ошибки загрузки из страниц; сохранить повторные запросы.
4. Перенести отказы банка в попап с кодом. Проверить повторное открытие причины и сохранность формы.
5. Проверить тесты, сборку, lint и браузер на узком/широком экране. Обновить документацию.
